# Hướng dẫn làm việc trong Test-Vinabrain

Trước khi đọc hoặc sửa code, phải đọc toàn bộ `project content/working-principles.md` và áp dụng cho phiên hiện tại.

Repo này là **Test-Vinabrain**, độc lập hoàn toàn với repo Vinabrain/VContent khác. Không được đọc, sao chép hoặc sử dụng cấu hình Git, Vercel, Supabase, biến môi trường, dữ liệu hay tài liệu nguyên tắc từ project khác để suy đoán cho repo này.

Nếu đường dẫn workspace, Git remote, Vercel project hoặc Supabase project không khớp với tài liệu nguyên tắc, dừng mọi thao tác ghi và xác minh lại phạm vi.
